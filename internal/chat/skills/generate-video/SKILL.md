# 生成视频

在 ScriptAgent 对话中使用。入口为技能菜单「生成视频」、`/生成视频` 或 `/generate-video`；自然语言如「把上面的脚本生成视频」也可触发。

- 优先使用本次明确提供的画面描述，否则沿用当前对话最近的脚本或提示词。没有可用描述时，在视频设置中请用户填写；不要凭空编造脚本。
- 提取可直接交给视频模型的画面、动作、镜头、口播和风格描述，去掉开场白、解释、使用建议与参数说明。输出时以“视频生成提示词”作为独立标题，正文使用 text 代码块；将参数放在正文之后的“视频参数”章节。
- 在对话内创建待确认视频卡片，预填提示词、时长、比例、分辨率和声音。优先采用用户指定参数，未指定时使用 5 秒、9:16、720P、有声。不要打开生成视频弹窗。用户可以在卡片中编辑和选择参考素材，必须点击“确认并生成视频”后才提交真实任务；不要把准备草稿或普通文本回复当作提交成功。
- 纯文本生成不要求产品。图片或视频参考需从当前账号可访问的产品资料选择；不要用本地附件名假装已上传的素材 ID。
- 任务关联当前对话，新对话提交时先建立对话。显示服务端返回的真实状态，完成后可预览与下载，失败时保留输入并显示错误。
- 用户只要求解释流程、编写视频提示词，或明确表示不要生成时，不触发成片提交。
- 此 Skill 的执行入口由应用的对话内确认卡片承接；聊天模型没有直接生成工具时，指导用户使用 `/生成视频` 创建卡片，不得声称已经提交任务。
