# UGC 视频生成

## 今日交付闭环

1. 在 Agent 对话输入框中打开“生成视频”，沿用当前对话的产品资料和创意空间。
2. 选择产品图片或视频作为参考，也可直接使用文字生成视频。
3. 描述人物、场景、动作、口播和产品露出方式。
4. 服务端向 DashScope Wan 提交异步任务并持续查询状态。
5. 当前对话实时展示任务状态与成片；“历史 > 视频结果”统一提供查看和下载。

## 产品默认值

- 图片生成视频优先，更容易保持产品外观。
- 参考素材可选无参考、产品图片或产品视频；参考视频会先上传到百炼临时存储。
- 分辨率支持 `480P`、`720P`、`1080P`，默认 720P。
- 时长支持 2～30 秒内的任意整数；含参考视频时，输入与输出总时长不能超过 30 秒。
- 声音可开启或关闭，对应接口的 `audio` 参数；关闭后成片不包含音轨。
- 统一使用 `wan3.0-video-prime`，请求通过 `media` 区分参考图片和参考视频。

## 状态与保存

视频任务按用户及对话归档，状态包括准备生成、已提交、生成中、已完成和生成失败。服务重启后会继续查询已提交的任务。平台生成链接具有时效，因此完成后会将 MP4 保存到 `uploads/generated`。

## 接口

- `GET /api/videos`：当前用户的视频任务。
- `POST /api/videos`：创建视频任务。
- `GET /api/videos/{id}`：读取进度。
- `GET /api/videos/{id}/file`：预览或下载本地成片。
- `POST /api/videos/{id}/retry`：失败后重新生成。

## 后续演进

- 从脚本或分镜一键带入视频描述并保留 CID 素材引用。
- 支持多镜头生成、排序、配音、字幕、音乐和最终合成。
