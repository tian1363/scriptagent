# 主动 Agent 设计

## 目标

ScriptAgent 不只响应输入，还会根据用户已有的创作目标、资料完整度和任务结果提出下一步行动。主动性必须可解释、可忽略、可追踪，任何会消耗额度或改变内容的动作都需要用户确认。

## 能力复用

- 创意空间：复用长期目标、营销目标、阶段和产品绑定，作为建议的业务边界。
- 产品资料与素材：复用资料完整度和图片/视频资产，判断创作是否缺少真实依据。
- 视频任务：复用异步状态，在视频完成后提醒用户查看结果并继续迭代。
- 创意雷达与长期记忆：后续可将新证据、内容疲劳和已确认结论作为实验建议来源。
- Agent Runtime 与可观测性：实际执行继续走现有运行时，建议层只负责发现机会和取得用户确认。
- 用户隔离：建议直接绑定用户，沿用现有认证和资源所有权模型。

## 第一版触发器

| 触发器 | 判断 | 建议行动 |
| --- | --- | --- |
| `missing_product` | 空间未绑定产品 | 完善空间 |
| `missing_assets` | 已绑定产品但没有图片/视频 | 打开产品资料并添加素材 |
| `stale_space` | 空间 7 天未推进 | 从原上下文继续创作 |
| `video_completed` | 视频异步任务完成 | 查看视频结果 |

建议使用用户与触发证据组成的去重键。用户忽略后不再重复生成同一条建议。

## 交互原则

1. 首页先展示最多三条高优先级建议，说明原因并给出一个明确动作。
2. 创意空间在对应空间内展示“下一步”，减少用户在页面间寻找入口。
3. “忽略”只关闭建议；“执行”先记录接受状态，再跳转或进入现有 Agent 流程。
4. 第一版不调用模型生成建议，避免无意义的 Token 消耗；后续可在规则命中后用模型优化摘要，而不是让模型无限扫描。

## 后续演进

- 把创意雷达中的新信号转成待确认实验，并在用户确认后写入长期记忆。
- 增加建议到执行到结果的转化指标，衡量接受率、完成率和创作周期缩短比例。
- 为失败任务提供带原因的恢复建议，但限制重试次数和预算。
- 支持定时扫描与站内通知；默认只对高优先级变化提醒，避免打扰。
