# 角色库与角色图控制

## 技术选择（2026-09-06）

本次采用账号独立的服务端角色库：上传已有角色，或使用 Qwen 生成新角色；选定参考角色后通过图片编辑生成新造型。角色库中的图可直接作为工具箱「换模特」的目标图。没有预置未经授权的人物照片，也没有将文字模板冒充现成数字人。

| 方法 | 适用场景 | 本次处理 |
| --- | --- | --- |
| 自有角色图库 + Qwen 图片生成/编辑 | 建立品牌角色、复用参考图、调整服装和场景 | 已接入 |
| HeyGen Photo Avatar | 以人物照片建立口播数字人并制作讲解视频 | 暂未接入，需要独立服务配置；不是通用视频换人方案 |
| InstantID / IP-Adapter + ControlNet | 独立身份参考、姿态/深度控制、局部重绘 | 后续更高控制需求的候选，需要 GPU 部署与模型许可核验 |

官方资料：[Qwen 图片生成 API](https://help.aliyun.com/en/model-studio/qwen-image-api)、[Qwen 图片编辑 API](https://help.aliyun.com/en/model-studio/qwen-image-edit-api)、[HeyGen Photo Avatar](https://developers.heygen.com/photo-avatar)、[InstantID](https://github.com/instantx-research/instantid)、[Diffusers IP-Adapter](https://huggingface.co/docs/diffusers/using-diffusers/ip_adapter)。

Qwen 支持图片参考、文字编辑要求、尺寸与种子参数。相同种子不是身份一致性的保证。IP-Adapter 可以与 ControlNet 的结构条件组合；若需严格固定姿态或局部保留，应进一步接入姿态图、蒙版和效果评估，不能仅靠增加提示词。

## 使用

1. 打开工具箱「换模特」，点击「从角色库选择」或「AI 生成角色图」。
2. 上传 PNG/JPG，或选择创作设定模板并调整外观、年龄、发型。
3. 设置服装、表情、姿态、构图、背景和光线；更多控制中设置尺寸、种子、排除内容。
4. 要延续身份，选择已有角色作为身份基准，或在角色卡点击「改造型」。编辑请求发送真实参考图，并要求保持五官、肤色、年龄与发型。
5. 在原图/新图对比中确认效果后，点击「使用此角色」，填入当前版本。

设置中需要分别连接「图片生成」和「图片编辑」能力。生成支持 `qwen-image-2.0` 系列；编辑还支持 `qwen-image-edit-plus/max`。接口必须使用账号所属地域的 Qwen `multimodal-generation/generation` 地址。本功能不会回退到文本模型，未配置时显示明确错误。

## 保存与边界

- 角色和生成参数保存在服务端，按登录账号隔离；图片接口也检查所有权。单账号最多 200 个角色。
- 上传图片最大 10MB，宽高 384–3072 像素；校验实际图片内容，不依赖文件后缀。
- 每次生成 1 张，异步显示生成中/成功/失败；关闭弹窗仍会继续。服务器重启时未完成任务标记失败，不自动重新收费生成。
- 生成图片及时下载到本地存储，避免依赖临时签名链接。下载不会携带模型 API Key。
- 服装、表情、姿态等是语义控制，尺寸与种子是实际模型参数。没有像素级身份锁定、姿态骨架或局部蒙版编辑；采用前需要对比确认。
- 当前接通的是角色图生成和工具箱选图。批量视频换模特、口型与成片管理仍待接入。

## 验证

通过测试替身验证参考图、尺寸、种子与提示词发送，以及鉴权信息不进入图片下载请求。接口测试验证登录、账号隔离、角色上传、跨账号引用拒绝与缺少图片配置的错误。未进行付费模型实测；浏览器验收受管理员策略检查阻挡。
