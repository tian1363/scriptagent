## 2026-09-06 · 自托管 Beta 更新

对应提交：`3508764`—`055d2e7`

### 新增

- **电商工具箱**：新增独立工作区，可批量整理参考内容、生成和编辑多个版本，并保存本地方案。
- **图片引用提示词**：在视频创作输入区支持通过 `@` 引用已上传图片，为不同参考图分别补充用途说明。
- **运营后台**：管理员可查看运营概览，并在后台创建、筛选和停用注册邀请码。
- **邀请码追踪**：记录邀请码备注、有效期、状态、使用账号和使用时间；完整邀请码仅在创建时展示一次。
- **部署基础设施**：增加 Dockerfile、Compose 配置、持续集成、Dependabot、备份脚本、安全政策和隐私说明。

### 改进

- 主导航改为更紧凑的折叠式布局，并为 Beta 阶段增加清晰标识。
- 邀请注册支持过期与停用校验，账号创建和邀请码核销在同一事务内完成。
- 用户 API Key 可使用 AES-256-GCM 加密保存；上传文件增加类型、大小和路径安全校验。
- 登录会话会再次检查账号状态，已停用账号不能继续访问。
- 完善多账号数据隔离测试、管理员权限测试和电商工具箱批处理测试。

### 安全变更

- 注册流程不再自动授予管理员权限，首个注册账号也默认为普通成员。
- 实例最多绑定一个管理员，必须由部署者使用已有账号 ID 显式配置。
- 管理员接口同时校验登录状态、账号角色和服务器绑定 ID，前端参数不能自行提升权限。
- 未配置管理员时，系统不会默认选择或猜测管理员账号。

### 升级说明

1. 升级代码并重新构建前端：

   ```bash
   git pull origin main
   npm --prefix web/app ci
   npm --prefix web/app run build
   ```

2. 如需使用运营后台，先注册目标账号，再将账号 ID 写入环境变量 `SCRIPT_AGENT_ADMIN_USER_ID`，或写入数据目录的 `admin-user-id` 文件。
3. 如需保存用户 API Key，必须设置 `SCRIPT_AGENT_ENCRYPTION_KEY`；生产环境不要使用示例值。
4. 重启服务。数据库字段会在启动时自动迁移，但升级前仍建议备份 `data/` 和 `uploads/`。
5. 管理员正常登录后，侧栏会显示“运营后台”；普通成员不会看到该入口。

详细配置参见[邀请测试部署指南](invite-deployment.md)，电商工作流参见[电商工具箱说明](ecommerce-toolbox.md)。

### 已知限制

- 当前仍为自托管 Beta，建议仅用于小范围邀请测试。
- 图片引用交互已完成构建，但本轮自动化浏览器未能通过本地地址的安全策略校验，因此视觉和交互回归仍需人工确认。
- 运营后台目前聚焦概览和邀请码管理，不等同于完整的多租户运营平台。
