# 隐私与可接受使用说明

> 本文是邀请测试阶段的产品说明模板。实际运营者应根据部署地区、主体和第三方供应商补充正式法律文本。

## 会处理的数据

ScriptAgent 会保存账号邮箱和称呼、产品资料、用户上传的图片/视频/文档、对话内容、生成结果、任务状态和模型调用统计。密码只保存哈希；用户提供的模型 API Key 加密保存。

## 数据用途

这些数据用于身份验证、恢复创作上下文、执行模型任务、展示历史结果、排查故障和控制使用成本。默认不把 Prompt 或模型输出正文发送到 Langfuse；只有部署者显式开启内容采集时才会发送。

## 第三方处理

当用户调用文本、图片或视频模型时，相关 Prompt 和所选素材会发送给用户选择的模型服务商。用户应阅读对应服务商的隐私政策和数据保留规则，不应上传无权处理的个人信息或商业机密。

## 用户责任

用户不得使用本项目：

- 侵犯著作权、肖像权、商标权或商业秘密；
- 制作欺诈、冒充、骚扰、仇恨或违法内容；
- 未经授权处理未成年人或其他敏感个人数据；
- 绕过额度、注册、访问控制或安全限制；
- 对服务或第三方模型发起攻击、批量滥用或自动化消耗。

## 数据管理

邀请测试期间，账号删除、数据导出和纠错请求由运营者人工处理。运营者应建立响应渠道、备份保留周期和删除流程，并在扩大测试前把这些能力产品化。
