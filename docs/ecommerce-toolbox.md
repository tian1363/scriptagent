# 电商人工具箱：批量差异化素材

## 原产品集成

这是 ScriptAgent 原应用内的功能，沿用现有登录、侧栏、产品资料接口与视觉规范。

入口：侧栏「电商人工具箱」，或原应用地址的 `/#toolbox`。没有单独的工具箱网站或独立预览页面。原先的 `toolbox-preview.html` 和开发预览组件已移除。

## 布局

- 顶部：批次名称对应的工作区、换模特／换文案／换产品、已存批次与保存草稿。
- 左侧：所有版本共用的原视频、预览、批次名称、分辨率、保留要求。
- 中间：差异化版本清单；勾选、全选、复制、移除、添加和批量导入。
- 右侧：当前版本的模特图／文案／商品信息；修改只影响该版本。
- 底部：选中数量、已配置数量、缺项与重复提示，检查整批配置和导出清单。
- 较窄窗口：共用素材移到顶部；手机端版本列表和详情上下排列。

每种工具保留自己的版本列表，默认提供三个空版本，每批最多 30 个。当前一次检查一种替换类型，没有自动组合多个维度形成笛卡尔积。

## 批量操作规则

上传多张模特／商品图片，每张对应一个版本。导入优先填入空版本，移除未使用的空占位，保留已经编辑的内容。超出 30 个版本时整体拒绝导入，避免静默丢失素材。

多版文案以单独一行 `---` 分隔，保留版本内的段落。单版上限 3000 字符。

统计只计算勾选版本。相同图片和要求、相同文案和修改范围会提示重复；版本名称不同不会被视为内容差异。文件参考通过文件名、大小、修改时间比较，素材库通过素材 ID 比较。这不是视觉相似度检测。

换产品默认要求确认新商品文案；取消此选项时提醒核对原文案规格和功效。视频时长提示使用粗略口播估计，不是音频合成结果。

## 保存与兼容

IndexedDB 保存原文件、所有工具的版本列表和统一参数，按当前账号 ID 区分列表。数据仅在当前浏览器保存，不跨设备同步，不代替服务端授权机制。

旧单版本草稿恢复时转换为批次结构，不删除旧草稿。切换原产品侧栏保留编辑内容并暂停原视频播放。

## 实际能力边界

已完成批量配置和检查前端。尚未接入批量生成、字幕转写、自动文案差异化、图片与视频混合参考、配音口型和成片结果管理。

界面不显示模拟进度或成片。检查面板明确显示「生成 N 条 · 待接入」，当前可保存整批配置和导出清单。

现有 `POST /api/videos` 要求所有参考素材与单一 `mode` 匹配并属于同一产品，不能直接承接独立原视频加多种目标图片。后续需要批次父任务与版本子任务：共用原素材，每个子任务有独立输入、状态、错误和结果；失败按版本重试，不重复提交已成功的版本。

建议契约包括 `batch_id`、`source_video_id`、`type`、统一规格，以及 `variants[]`（版本 ID、目标图片 ID、新文案、保留要求）。Agent 可以调用同一批次接口，工具箱无需依赖对话。
