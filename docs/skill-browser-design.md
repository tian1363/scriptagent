# 技能浏览信息优化 · 2026-09-06

## 现状依据

基于用户本轮提供的技能窗口截图：左栏约占三分之一，图标、名称、描述、分类同时占位；长描述被截断。详情重复显示标题、名称和描述，正文又嵌套在容器内，实际阅读区偏小。本次未进行竞品登录态实机审查，以下是官方交互文档调研。

## 参考产品

- [Claude 技能管理](https://support.claude.com/en/articles/12512180-use-skills-in-claude)：Customize 集中管理，列表呈现简短用途，点击查看详情；管理操作按需进入。
- [Claude 组织技能](https://support.claude.com/en/articles/13119606-provision-and-manage-skills-for-your-organization)：通过搜索和分区导航，点选预览描述与内容。
- [Cursor Agent Skills](https://prod.cursor.com/docs/skills)：支持自动匹配与手动 slash 调用。可借鉴把日常调用和完整配置阅读分开，而不要求每次使用前阅读全部技能文件。

## 已实施

1. 左栏固定为 220px，不再随宽屏扩张；列表仅保留名称、分类、小图标，描述移至详情。新增标题/描述/分类搜索和无结果提示。
2. 提供收起/展开目录，阅读时正文占满宽度。
3. 详情保留标题、来源和分类；用途只出现一次，内部标识放入默认折叠的技能信息。
4. 移除正文重复背景与边框，保留正文独立滚动与固定底部操作；切换技能重置正文容器。
5. 760px 以下使用技能下拉选择，避免列表挤占阅读高度。
6. 使用按钮改为「在对话中使用」，保留创建、编辑和原有调用行为；统一新建入口为产品珊瑚色。

这是一项现有界面的定向优化，没有新增市场、收藏、权限或自动调用机制。

前端构建、差异空白检查通过；本地服务返回了新构建资源。浏览器交互与缩放验收未完成，既有管理员策略检查阻挡浏览器访问。本次截图结论只覆盖用户展示的状态，不代表完整流程或无障碍合规审查。
