# ScriptAgent brand

> Last updated: 2026-08-28 · Applies to the current React single-page app.

完整的组件、布局、交互、Agent 状态与验收规范见 [`docs/frontend-design-guidelines.md`](docs/frontend-design-guidelines.md)。

- Canvas: `#FBF7F0` / `#FFFDF9`
- Ink: `#171513`
- Creative accent: `#F0523D`
- Principle: use one warm creative accent only; avoid purple and blue product-brand states.
- Tone: an approachable agent workspace for work that grows over time, not a generic dashboard.
- Navigation: default to a lightweight icon rail; expansion must not cover content.
- Chat: composer, active controls, user messages, focus rings, and progress accents use the coral brand family rather than blue or purple.
- Surfaces: prefer spacing, warm neutral fills, typography, and elevation over repeated borders.
- Copy: remove implementation jargon and filler; show concise status, action, and final result.
